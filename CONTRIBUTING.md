# Memberi masukan

Terima kasih telah mencoba SIMRS.

Repositori ini menerima laporan masalah dan masukan penggunaan. Kode sumber aplikasi tidak dibuka untuk kontribusi pada tahap preview ini, sehingga pull request tidak dipakai sebagai jalur perubahan.

Saat melapor, sertakan:

1. Versi paket.
2. Halaman atau menu yang dibuka.
3. Langkah untuk mengulang masalah.
4. Hasil yang muncul dan hasil yang diharapkan.
5. Tangkapan layar atau log yang telah dipastikan tidak memuat data rahasia.

Jangan pernah mengirim data pasien sungguhan, `setelan.json`, kata sandi, token, atau kredensial.
